Sources
Manage ingest pipelines and source connectors.
Sources are the ingest pipelines that fetch or scan upstream media. Use Library for playable assets and Pools for programming groups.
INGEST
Add source
Add a connector for the upstream media feed you want Stream247 to ingest. Sources are ingestion pipelines, not the playable catalog itself.
CHOOSE A SOURCE TYPE
Local media library
Play files already stored on this server from the shared media folder.
Best for self-hosted operators who want a simple, stable local catalog without relying on upstream URLs.
Direct media URL
Add a single directly reachable video file or streamable media URL.
Useful for CDN-hosted MP4 files, one-off replay clips, or fixed archive URLs.
YouTube playlist
Ingest every video from a YouTube playlist into your catalog.
Best when you already curate a replay or archive playlist on YouTube.
YouTube channel
Track a whole YouTube channel and ingest its uploaded videos as assets.
Good for archive channels where the upstream creator keeps publishing new replay content.
Twitch VOD
Add a single Twitch VOD as a replay source.
Useful for one-off archive imports or special event replays.
Twitch channel archive
Track archived VODs from a Twitch channel and keep ingesting new ones over time.
Best for replay channels built from an existing Twitch creator archive.
